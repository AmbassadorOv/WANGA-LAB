# INTERNATIONAL DRIFT PROPAGATION NETWORK

## Project Status

Research project under development.

## Purpose

Measure and reconstruct how time-varying changes in AI and information systems appear across geographic regions, languages, and information surfaces, and determine whether observed changes form reproducible temporal relationships across locations.

The project is broader than election monitoring. Elections are one event class that can provide a high-density temporal anchor for observation.

## Core Research Question

Can measurable drift signatures observed in one geographic or informational environment be detected later, earlier, or concurrently in other environments, and can those relationships be reproduced and independently evaluated without assuming causality?

## Four-dimensional observation model

`TIME × GEOGRAPHY × LANGUAGE × SURFACE`

Surfaces may include:

- AI/model systems
- Search systems
- News/public-information systems
- Other explicitly documented information surfaces

## Propagation model

A detected relationship is represented as an observed temporal edge:

`Region A → Region B`

`Language A → Language B`

`Surface A → Surface B`

The arrow means that a defined change in A preceded, followed, or temporally coincided with a defined change in B. It does not by itself establish causal influence.

## Drift signature

Each candidate relationship should preserve:

- timestamp and time window
- source region and destination region
- source and destination language
- source and destination surface
- probe/test identifier
- baseline reference
- measured delta
- drift class
- evidence references
- reproduction status
- attribution status
- uncertainty and missing data

## Research sequence

`BASELINE → OBSERVE → NORMALIZE → ALIGN → DETECT → MAP → RELATE → REPRODUCE → ATTRIBUTE → VERIFY`

## Event anchors

The network can use high-information events as temporal anchors, including:

- elections
- major public-information events
- major policy events
- market events
- infrastructure events
- major model/system releases
- other explicitly documented events

An event anchor supplies context and timing. It is not automatically a causal explanation.

## Main outputs

1. International Drift Timeline
2. Regional Drift Profiles
3. Cross-Language Drift Profiles
4. Cross-Surface Interaction Graph
5. Candidate Propagation Edges
6. Reproduction Records
7. Attribution Records
8. Unresolved Relationship Register
9. Global Drift Visualization Dataset

## Scientific boundary

The project does not infer political preference, political intent, or causal influence from temporal correlation alone. Election-related observations are treated as technical event-context data. Findings must remain traceable to observations and evidence.

## Relationship to Global Drift Network

This is a dedicated research project inside the Global Drift Network. It consumes observations from the common network while maintaining its own hypotheses, relationship records, verification state, and outputs.
