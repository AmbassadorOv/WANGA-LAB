# Source Provenance

For every external source used in the White Paper, record:

- source ID;
- title;
- publisher/author;
- publication date;
- canonical URL;
- retrieval timestamp;
- relevant passage or finding;
- scope/population;
- source type;
- limitations;
- content hash where practical and lawful.

Regulatory claims, statistical claims, and claims about external research should not rely on an undated secondary summary when the primary source is available.
