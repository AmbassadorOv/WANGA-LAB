## Standard Group Interface
Every researcher group uses the same structure:

Research question → assigned subdomain → complementary groups → GitHub repository/subdirectory → experiment or implementation → evidence → review → integration.

No subdomain is expected to solve the entire architecture. Groups are complementary by design; connections between them are maintained as explicit interfaces.
