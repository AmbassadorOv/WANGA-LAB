# Visual & Canva Design Export Specifications

This specification outlines visual design principles for reproducing the diagrams of *Sod Ha-Bechinah* in Canva or architectural design suites.

## Aesthetic Guidelines

- **Style**: Clean, scientific, minimalist architectural aesthetic.
- **Palette**:
  - Dark Slate background (`#0F172A`) or Clean White (`#FFFFFF`).
  - Primary Cyan/Accent Blue (`#0284C7` / `#38BDF8`) for mathematical objects.
  - Emerald Green (`#10B981`) for structural invariants and balance.
  - Muted Gold/Amber (`#F59E0B`) for high-level source nodes.
  - Slate Grey (`#64748B`) for structural edges and projection maps.

## Diagram Blueprint Hierarchy

### 1. Master Hierarchy (Hierarchy Flow)
`Ein Sof / Source` → `Scale` → `Relation` → `Bechinah` → `Information Space (Ta'amim / Nekudot / Tagin / Otiyot)` → `Akudim / Nekudim / Berudim` → `Tikun / Balance`

### 2. Four Information Layers
Stacked horizontal bands or concentric rings:
1. **Ta'amim** (Syntactic / Prosodic Master Layer)
2. **Nekudot** (Vocalic / Internal State Layer)
3. **Tagin** (Structural Annotation Layer)
4. **Otiyot** (Symbolic Carrier Layer)

### 3. Transformation Between Levels
- Forward Map ($\Phi_i: \Omega_i \to \Omega_{i+1}$): Refinement / Generation.
- Reverse Map ($\Pi_i: \Omega_{i+1} \to \Omega_i$): Projection / Coarse-graining.
- Explicit label for Information Loss ($\mathcal{L}_n = D(\Omega_{n+1}, \Psi_n(\Omega_n))$).

### 4. Tree of Life Sefirotic Network
10 Nodes labeled $Q_1$ through $Q_{10}$ with attribute tuples $Q_i = (M_i, R_i, S_i, V_i, \Phi_i)$ connected by 22 channels (representing the 231 relational gates $\binom{22}{2}$).
