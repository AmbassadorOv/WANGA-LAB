# Notary Evidence Submission Form

This checklist is for presenting an existing evidence package to an Israeli notary. It does not ask a notary to certify facts outside the notary's statutory authority.

- Executed agreement
- Exact delivered JSON
- SHA-256 manifest
- RFC 3161 TSR and verification output
- External anchoring receipt, if actually confirmed
- Identity documents requested by the notary
- System verification report

Record the evidence identifier, exact filenames and SHA-256 values, presentation date/time, versions, verification software/version, and deviations or missing artifacts.

The notary should record only matters independently verified. A hash must not be presented as proof that financial calculations are true.

Obtain transaction-specific Israeli legal advice before relying on this package in litigation.
