# From Software Benchmarks to Physical-World Evaluation

**Evidence class:** INSTITUTIONAL RESEARCH REPORT  
**Window:** 2026-09-18 to 2026-09-19.

## Abstract

Harvard researchers recently described RLE-Bench, an evaluation tool for testing AI coding agents on tasks involving engineering a physical robot. The important compositional move is that an agent's competence is evaluated through a task that ultimately interacts with physical engineering constraints rather than only text or software artifacts.

## Structural transition

**Text task → Software artifact → Physical system constraint → Observable result**

This creates a useful bridge between AI evaluation and engineering science.

## Research composition

The same pattern can connect:

- AI agents and robotics;
- software engineering and laboratory automation;
- simulation and physical validation;
- planning and control;
- code generation and experimental reproducibility.

## Drift question

A system can remain stable on a software benchmark while changing behavior when the task includes hardware constraints, resource limits, sensor uncertainty, or physical feedback.

Therefore:

**benchmark stability ≠ universal behavioral stability.**

That is a research hypothesis, not a measured conclusion.
