## Primary Map

**[07_ARCHITECTURAL_MAP.md](07_ARCHITECTURAL_MAP.md)** is the main conceptual map of WANGA as an idea. It is intentionally distinct from the WANGA computational architecture.

The map connects:

- scientific disciplines and knowledge architecture;
- education and global learning;
- AI and computation;
- organizations and institutions;
- law and governance;
- economics, finance, and production;
- cities, infrastructure, energy, and health systems;
- historical transformations;
- thinkers, researchers, and paradigms;
- application domains.

## Central Causal Principle

**Problem / Need → Requirement → Possibility → Required Structure → System → Observation → Learning → Structural Revision**

The map is not a claim that every domain has the same mechanism. It identifies a common architectural question: whether inherited structure should be accepted as the starting boundary of possibility.

## Relation to WANGA-X

WANGA-X is one computational expression of the larger WANGA philosophy:

**Requirement → Required Neural Computation → Neural Computational Structure → Blueprint → Neural Computer**

The conceptual map therefore describes the architecture of the idea; WANGA-X describes one technological realization.

## Evidence Discipline

The project distinguishes:
- philosophical thesis;
- historical interpretation;
- documented research;
- proposed application;
- implemented mechanism;
- empirical evidence.

No inclusion of a thinker, field, or historical event is by itself a claim of priority, correctness, or equivalence.
