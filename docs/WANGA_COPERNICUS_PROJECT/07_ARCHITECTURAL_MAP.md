# WANGA Conceptual Architectural Map

## Purpose

This is the primary map of WANGA as an idea-level architecture. It is not the architecture of the WANGA computational system. It maps the domains, disciplines, historical transformations, researchers, concepts, and application areas that belong to the WANGA Copernicus thesis.

## Primary Causal Architecture

**Problem / Need → Requirement → Possibility → Required Structure → System → Observation → Learning → Structural Revision**

The central rule is that inherited structure is an object of examination, not an automatic boundary of possibility.

## Researcher and Thinker Map

WANGA should map thinkers by the problem they illuminated and by the boundary of the framework in which they worked, rather than by prestige or ranking.

Examples of research nodes include:
- Norbert Wiener — automation, communication, human-machine relations, cybernetics
- Noam Chomsky — language, formal structure, cognition, critique of statistical accounts
- paradigm-changing scientists and philosophers across physics, mathematics, biology, economics, computer science, social science, and philosophy

The map must distinguish:
**what a thinker established → what problem they exposed → what assumptions their framework retained → what questions remain outside that framework.**

This is not an evaluation of intelligence or personal capability.

A key diagnostic question is:

**Where does increasing investment in an inherited structure increase complexity, dependency, or risk without changing the structure that created the bottleneck?**

## Three Levels of WANGA

### Level 1 — Diagnosis
Identify the inherited frame and the problem it was originally intended to solve.

### Level 2 — Architectural Reversal
Separate the current requirement from the inherited structure and derive the structure from the requirement.

### Level 3 — Continuous Evolution
Keep the architecture revisable as requirements change, avoiding a new permanent box.

## Relation to WANGA-X

WANGA-X is one technological expression of this higher-order architecture:

**Requirement → Required Neural Computation → Neural Computational Structure → Blueprint → Neural Computer**

WANGA-X is therefore a computational branch of the larger conceptual map, not the whole map.

## Non-Equivalence Rule

The map must never imply that all domains have identical mechanisms. The common element is the architectural principle: **requirements are examined before inherited structures are accepted.**

## Evidence Discipline

The map separates:
- philosophical thesis
- historical interpretation
- documented research
- proposed application
- implemented mechanism
- empirical evidence

No historical or scientific priority claim is implied merely by inclusion in the map.
