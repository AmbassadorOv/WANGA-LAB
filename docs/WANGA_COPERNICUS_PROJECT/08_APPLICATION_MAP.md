# WANGA Copernicus Application Map

## Selection Principle

Applications are not selected because they are fashionable. They are selected where the inherited architecture itself may be a significant part of the problem.

## Primary Domains

| Domain | Structural question | WANGA direction |
|---|---|---|
| AI / computing | Is the fixed architecture defining the computation? | Requirement-derived computation and architecture |
| Education | Is the learner fitted to a fixed pathway? | Requirement- and capability-derived learning |
| Scientific research | Are disciplinary boundaries constraining the question? | Problem-first cross-disciplinary architecture |
| Engineering | Is a platform dictating the solution? | Requirement-first system design |
| Manufacturing | Is production organized around inherited machinery? | Demand/requirement-derived process architecture |
| Organizations | Is work forced into inherited hierarchy? | Task/requirement-derived organization |
| Law | Is a new problem forced into old categories? | Examine whether the category fits the requirement |
| Public administration | Are procedures preserved after their purpose changes? | Purpose and service requirement first |
| Governance | Does institutional form become an end in itself? | Human requirement and lawful authority first |
| Economics / finance | Do mechanisms preserve themselves after conditions change? | Requirement and incentive architecture review |
| Urban systems | Does infrastructure constrain the future need? | Need-derived planning |
| Energy | Does the grid architecture dictate demand behavior? | Requirement-aware system architecture |
| Health systems | Does protocol structure dominate the actual requirement? | Requirement, evidence, safety, and adaptability |
| Knowledge systems | Does taxonomy constrain discovery? | Question-driven knowledge architecture |
| Resilience | Does risk control add layers without removing the structural source? | Structural risk diagnosis |

## Diagnostic Test

For each domain ask:

1. What problem was the existing structure originally designed to solve?
2. Which conditions have changed?
3. Which parts of the structure are genuine constraints?
4. Which parts are inherited assumptions?
5. Does continued optimization increase complexity or risk?
6. Can the requirement be stated independently of the current structure?
7. What structure would follow from the requirement?
8. Can the new structure remain revisable?

## Core Hypothesis

The strongest candidate domains are those in which:

**increasing system scale → increasing structural complexity → increasing dependency/risk → diminishing ability to change the underlying architecture.**

WANGA treats this as a research hypothesis to be tested case by case, not as an assumption that every existing institution has failed.
