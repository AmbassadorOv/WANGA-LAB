# Vitruvius Three-Family Branch Tree

Every discovered branch is assigned to one of three top-level families and then
wrapped using the same recursive neural pattern.

```
GLOBAL GITHUB
   |
   +-- COMPUTATIONAL / NEURAL
   |      +-- Neural Computation
   |      +-- Runtime Fabric
   |      +-- Architecture Systems
   |
   +-- EVIDENCE / GOVERNANCE
   |      +-- Evidence & Drift
   |      +-- Governance & Control
   |      +-- Assurance Services
   |
   +-- PUBLICATION / RESEARCH
          +-- Publication
          +-- Research & Composition

Each branch:
Branch -> Family -> Subfamily -> Neural Endpoint -> Global Neural Network
```

The classifier is deterministic and auditable. Classification is a topology
mapping, not proof that a branch is correct or verified. Protected Rational Logic
implementation remains outside automated copying/integration.
