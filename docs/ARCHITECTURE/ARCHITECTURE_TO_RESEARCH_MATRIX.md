# Architecture-to-Research Matrix

| Architectural layer | Research material to connect |
|---|---|
| Global Work Manager | work orchestration, task queues, state snapshots, execution policy |
| Model Fabric | model slots, providers, runtime normalization, model configuration |
| Digital Model Agents | agent roles, interfaces, execution contracts |
| Evidence & Provenance | hashes, provenance, evidence packages, audit records |
| Drift Forensics | definition/premise/inference/criterion drift and reconstruction |
| Rational Logic | structured reasoning and verification |
| Neural Thinking Machine | inference-time reasoning, memory and search |
| Perspective Layer | lateral/domain views and research composition |
| Publication Layer | articles, research sites, public evidence and indexing |
| Governance Layer | institutional interfaces and risk/evidence structures |

## Architectural principle

Research artifacts should be connected to the layer they inform, not forced into a software-project taxonomy.

The same artifact may legitimately connect multiple layers. Cross-links must preserve provenance and avoid duplicating the source artifact.
