# WANGA Lineage Tree

## Definition

The WANGA Lineage Tree is the independent registry for the complete developmental genealogy of the project.

It records not only the ancestry of ideas and architectures, but also every documented descendant produced from them. A descendant becomes a node in its own right and may generate a new lineage.

## Core principle

Nothing that develops from a registered node is lost from the genealogy.

origin → development → descendant → new lineage → further descendants → architectural integration

The tree is recursive and potentially branching without a fixed depth.

## What the tree records

Each node may represent:
- an idea
- a concept
- a hypothesis
- a model
- an architecture
- a component
- a method
- an artifact
- an experiment
- a finding
- a question generated by prior work

Each node receives a stable lineage_id.

## Development events

Every meaningful transition can be recorded as:
- introduced
- derived
- refined
- expanded
- constrained
- formalized
- implemented
- tested
- connected
- split
- merged
- superseded
- rejected
- reopened

## Recursive genealogy

A child is not merely an endpoint.

If node L-001 produces L-014, and L-014 later develops into L-031 and L-032, then:

L-001 → L-014 → {L-031, L-032}

Both descendants become independent lineage nodes and may themselves become parents of further branches.

## Integration with the architecture

The lineage tree answers where something came from and where it developed.

The Architecture Family Lineage answers how architectural families descended from one another.

The Global Architecture Registry answers where the current result sits in the architecture.

The integration layer connects them:

WANGA LINEAGE TREE → ARCHITECTURE FAMILY LINEAGE → ARCHITECTURE INTEGRATION → GLOBAL ARCHITECTURE

## Provenance rule

Never invent ancestry.

Every lineage edge should point to a source, artifact, decision, dated conversation record, or explicit documented derivation. If provenance is uncertain, mark it UNKNOWN_ORIGIN or UNVERIFIED_LINEAGE.

## Objective

The tree preserves the project's developmental memory so that the present architecture can be traced backward to documented origins and forward to documented descendants.
