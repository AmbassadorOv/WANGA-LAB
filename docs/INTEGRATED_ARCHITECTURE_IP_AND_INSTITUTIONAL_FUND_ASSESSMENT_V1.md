The current WANGA architecture is materially beyond a conventional multi-agent prototype in breadth, but it is not yet a validated autonomous multi-model runtime and does not yet contain the formal Rational Logic engine.

The next-month Rational Logic program is therefore treated as the principal architectural work, not as an accessory module.

The strongest future asset is the interaction between:
1. Global Work Manager;
2. Model Fabric and Digital Model Agents;
3. Evidence / Provenance;
4. Drift Forensics;
5. Verification;
6. Rational Logic;
7. Neural Thinking Machine;
8. Work Memory.

The external agent frameworks reviewed previously contribute execution patterns, but they do not replace this architecture.

## Wix-derived architectural direction

Wix publications are treated as research/architecture evidence and not as a substitute for machine-readable repository contracts. The current registry records 21 Wix contexts, but a complete content audit has not yet been verified.

The architecture should therefore absorb research concepts only after normalization into:
- explicit definitions;
- machine-readable contracts;
- testable invariants;
- evidence references;
- executable experiments.

No published Wix concept is treated as verified merely because it was published.

## Two-system interaction

The two principal systems should not be treated as independent products.

Operational WANGA produces:
- observations;
- model outputs;
- evidence;
- provenance;
- drift findings;
- conflicts.

Rational Logic consumes those inputs and returns:
- supported;
- not supported;
- contradicted;
- insufficient premises;
- undefined;
- out of logic scope;
- verification requirements.

Rational Logic also supplies acceptance conditions back to the operational system.

This creates a closed research loop:

OBSERVE -> REPRESENT -> REASON -> ACT -> VERIFY -> UPDATE MEMORY -> OBSERVE

## IP / patent position

A patent should not be described as already secured.

Under Israeli patent law, a patentable invention must be new, useful, industrially applicable and involve an inventive step. Israeli Patent Authority guidance also requires the specification to describe the technical problem, prior art, definition of the invention, differences/advantages, operation and examples where available. Public disclosure before filing can affect novelty. Therefore the unpublished Rational Logic implementation should not be publicly enablingly disclosed before patent counsel evaluates filing strategy.

The intended ownership model is institutional rather than personal:
- inventors should be identified accurately;
- the actual legal institute/entity intended to own the IP must be identified;
- rights should be transferred/assigned to that entity under appropriate agreements;
- the patent register should reflect the actual legal ownership.

Calling the asset "owned by the Israel branch of the Institute" is only legally meaningful once that branch is a recognized legal entity or holds the rights through a recognized parent/entity structure.

## Valuation framework

No defensible market value can be established from architecture documents alone.

The following are planning bands, not appraisals:

| Stage | Indicative strategic-IP planning band | Main uncertainty |
|---|---:|---|
| Current architecture, unvalidated runtime | ₪2M–₪6M | implementation maturity and market proof |
| Rational Logic formalized + executable prototype + tests | ₪8M–₪25M | patentability, reproducibility, differentiation |
| Patent application + working integrated system + external validation | ₪15M–₪50M | claim scope, validation, licensing demand |
| Granted/defensible IP + demonstrated deployments/licensing | ₪30M–₪100M+ | commercial traction and enforceability |

These bands must not be presented to investors, regulators, auditors or courts as an independent valuation. Professional IP valuation should use cost, market/comparables, income/DCF and/or real-options methods appropriate to the asset's maturity.

## Proposed institutional development vehicle

Working concept: an institutional technology-development fund for the Israel branch, subject to legal, accounting, tax and regulatory review.

Purpose:
- finance Rational Logic research;
- finance verification infrastructure;
- finance model/runtime integrations;
- finance patent prosecution;
- finance independent technical validation;
- reinvest licensing or commercialization proceeds into research.

The fund should be structurally separated from the patent itself:
Patent/IP holding entity -> licenses technology
Development fund -> finances approved research and development
Research institute -> governs scientific/technical program
External operators/advisers -> provide independent legal, IP, accounting and technical review

No automatic assumption should be made that a public "sovereign fund" can be created by a private institute under that label. The legal form, fiduciary duties, funding sources and regulatory status must be established first.
