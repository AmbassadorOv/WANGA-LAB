# Vitruvius Family-Atom Architecture

Vitruvius descends below family and subfamily to the **atom level of the architecture families**.

An atom is a smallest declared architectural concept that is independently useful for relationship analysis.

## Recursive structure

ARCHITECTURE SOURCE
→ FAMILY ROOT
→ SUBFAMILY / CHILD
→ FAMILY ATOM
→ SUBATOM
→ NEURAL ATOM ENDPOINT
→ GLOBAL NEURAL NETWORK

A family atom may belong to two or more root families. This is intentional: concepts such as state, evidence, provenance, work memory, translation, experimentation, lineage, governance and propagation can cross architectural boundaries.

Vitruvius therefore creates explicit CROSS_FAMILY_ATOM_BRIDGE relationships instead of forcing a multi-family atom into one family.

## Governance

Every atom carries its applicable P0-P7 governance layers. Governance is attached at the atom boundary so that descendants can inherit the relevant controls without inheriting unrelated controls.

## Neural wrapping

Every discovered atom receives a deterministic Neural Atom Endpoint. The endpoint folds into the WANGA Global Neural Network.

The mapper records topology; it does not treat discovery as verification.

## Source basis

The mapper reads the ten canonical architecture documents already registered for WANGA and extracts atomic concepts from their actual content, including hierarchy, headings, tables and architectural descriptions.
