# WANGA Copernicus — Project Map

WANGA is organized around **Copernicus as the intellectual core**. The other projects are not an unstructured collection: each belongs to a work group and is connected back to the core.

## Work Groups

### WANGA Copernicus — Core
זיהוי הקופסה, שינוי נקודת הייחוס, יציאה מהמסגרת, הגדרה מחדש של הבעיה ופתרון ללא יצירת קופסה חדשה.
- Articles: 001-010
- [Open group](groups/01-copernicus-core.md)

### Boxes, Boundaries & Convergence
איך קופסאות נוצרות, מתי גבולות מועילים, מתי הם ממצים את עצמם, ואיך תיקון עלול להפוך להתכנסות רקורסיבית.
- Articles: 011-030
- [Open group](groups/02-box-boundaries.md)

### Puzzle & Reconstruction
הפתרון כפאזל: חילוץ חלקים נכונים, זיהוי חלק חסר או ממוקם שגוי, והרכבה מחדש לפי יחסים ולא לפי הקופסה המקורית.
- Articles: 031-040
- [Open group](groups/03-reconstruction.md)

### History & Philosophy
יישום נקודת הייחוס הקופרניקנית על מהפכות מדעיות והיסטוריות, יחד עם פילוסופיה של המדע והשפה.
- Articles: 041-060
- [Open group](groups/04-history-philosophy.md)

### WANGA Method & Architecture
Requirement, Reference Point, Box Detection, Perspective, Evidence, Reconstruction, Verification ו־Reframing.
- Articles: 061-072
- [Open group](groups/05-architecture-method.md)

### AI, Drift & Neural Thinking
AI בתוך קופסה, Recursive Self-Improvement לעומת Recursive Convergence, Drift Forensics, Rational Logic ו־Neural Thinking Machine.
- Articles: 073-084
- [Open group](groups/06-ai-drift.md)

### Systems & Growth
המערכת הקיימת מול סביבת ניסוי, Capability Chains, תשתית לפני חזון ושני מנועי צמיחה בעלי ארכיטקטורות שונות.
- Articles: 085-092
- [Open group](groups/07-systems-growth.md)

### Scientific Reframing
שינוי מסגרת, שימור פתרונות בלי לשמר את הקופסה, שינוי מדעי והרכבה מחדש של מערכת.
- Articles: 093-100
- [Open group](groups/08-reframing.md)
