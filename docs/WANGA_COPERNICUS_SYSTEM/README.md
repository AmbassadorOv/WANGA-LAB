# WANGA Copernicus System

The WANGA Copernicus System is the research and publication layer for the project's Copernican method.

## Core rule

**Identify the box from outside the box.**

The project studies how inherited reference frames can be made visible, how useful solutions can be extracted from them, and how problems can be solved without automatically reproducing the frame that generated them.

## Corpus

100 individually addressable research articles organized into ten research families.

## Status model

SPECIFIED → RESEARCH DRAFT → SOURCED → TESTED → VERIFIED → PUBLISHED

GitHub is the technical source of truth. Wix is the public publication layer.
