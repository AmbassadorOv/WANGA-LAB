# קופרניקוס עצמו כמקרה מחקר

**WANGA Copernicus System — Article 043 / 100**

קופרניקוס עצמו כמקרה מחקר נבחן כאן לא כרשימת אירועים אלא כבעיה של נקודת ייחוס. קריאת היסטוריה מבחוץ פירושה להבחין בין האירוע עצמו לבין המסגרת שממנה בני התקופה ניסו להבין אותו.

המתודה הקופרניקנית אינה קובעת מראש שהמסגרת הייתה "שגויה". היא שואלת איזו דרישה, מגבלה, טכנולוגיה, מוסד או צורת ידע יצרו את המבנה, ומה השתנה לאחר מכן.

במקרה היסטורי נבנה מיפוי: **דרישה → מסגרת → פתרונות → תוצאות → גבול → שינוי נקודת ייחוס**. כך ניתן לראות כיצד פתרון של תקופה אחת הופך לתנאי הפתיחה של התקופה הבאה.

קופרניקוס משמש כאן כמקרה מחקר משום שהערך המתודולוגי שלו בפרויקט הוא שינוי נקודת הייחוס. אין צורך להרחיב מכאן לכל אסוציאציה על שמו; השאלה היא מה קורה כאשר המרכז שממנו מתארים את המערכת משתנה.

הניתוח ההיסטורי חוזר לאחר מכן ל־WANGA: לזהות את הקופסה, לצאת ממנה, להגדיר מחדש את הבעיה, לחלץ פתרונות שימושיים ולבנות יחסים חדשים.

המטרה אינה לשכתב את העבר אלא להפיק ממנו מבנה בדיקה. כל טענה היסטורית צריכה להישען על מקורות; כל מסקנה מתודולוגית צריכה להיות מובחנת מן העובדה ההיסטורית.

כך ההיסטוריה הופכת למעבדת ארכיטקטורה.
