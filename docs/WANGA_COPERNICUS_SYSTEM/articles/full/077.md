# Criterion Drift

**WANGA Copernicus System — Article 077 / 100**

Criterion Drift מפריד בין שלושה סוגי שינוי שיכולים להיראות זהים בתוצאה אך שונים בסיבה. Criterion Drift משנה את האופן שבו הצלחה נמדדת; Premise Drift משנה הנחות יסוד; Frame Drift משנה את המסגרת שמגדירה את הבעיה.

לכן WANGA אינו מסתפק בהשוואת תשובות. הוא שומר baseline, תצפיות, קריטריונים והקשר. כך ניתן לחזור לאחור ולשאול באיזה שלב השתנה המבנה.

במערכת AI, לפעמים נכון לפתור את הבעיה הנתונה. במקרים אחרים, הפתרון הנכון הוא לעצור ולבדוק אם הבעיה עצמה עדיין מוגדרת באותה צורה. זו פעולה קופרניקנית: להפוך את המסגרת לחלק מן האובייקט.

הבדיקה דורשת Evidence/Provenance, Reconstruction ו-Verification. המטרה אינה להעניק למודל סמכות מוחלטת, אלא לבנות מערכת שבה ההצעה ניתנת לבדיקה חיצונית.

כך Drift הופך מ"מודל השתנה" לשאלה מדויקת יותר: מה השתנה — התשובה, הקריטריון, ההנחה או המסגרת?
