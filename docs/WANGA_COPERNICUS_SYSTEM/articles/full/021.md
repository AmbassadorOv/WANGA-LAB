# לוגיקה בתוך קופסה

**WANGA Copernicus System — Article 021 / 100**

לוגיקה בתוך קופסה מנתח את היחס בין לוגיקה לבין המסגרת שבה הלוגיקה פועלת. לוגיקה יכולה להיות תקפה מקומית ועדיין להוביל למערכת שאינה מתאימה לדרישה, אם נקודת הייחוס עצמה לא נבדקה.

הארכיטקטורה הקופרניקנית מוסיפה שכבת בדיקה לפני ההסקה: **Requirement → Reference Point → Boundary → Relations → Reasoning → Action → Verification**. לכן לא מספיק לשאול האם המסקנה נובעת מן ההנחות; צריך לשאול האם ההנחות מייצגות את הדרישה.

המושג **לוגיקה מופרעת** משמש כאן לתיאור מצב שבו דפוסי הסקה ממשיכים לעבוד באופן מסודר לאחר שהמסגרת שהפעילה אותם חדלה להתאים. אין הכוונה לאי־רציונליות. להפך: דווקא עקביות מקומית יכולה לשמר את הכשל אם אין מנגנון שמאפשר לבדוק את המסגרת.

הפתרון אינו עוד כלל בתוך אותה מסגרת. הוא **Reframing**: להוציא את נקודת הייחוס אל שדה התצפית, לזהות אילו יחסים הם דרישה ואילו הם ירושה, ואז לבנות מחדש.

במערכת WANGA, התהליך מתחבר ל־**Rational Logic**, ל־Perspective Layer ול־Evidence/Provenance. הלוגיקה שומרת על עקביות; שכבת הפרספקטיבה בודקת מאיפה מסתכלים; הראיות בודקות מה התרחש בפועל.

הבדיקה הסופית היא מחזורית: **Observe → Represent → Reason → Act → Verify → Update Memory → Observe**. כך מערכת אינה מקבלת את הלוגיקה שלה כגבול קבוע, אלא משתמשת בה ככלי בתוך מערכת חיה.

לוגיקה בתוך קופסה הוא לכן מאמר על תנאי ההפעלה של החשיבה, לא רק על תוצאות ההסקה.
