# Live Systems

**WANGA Copernicus System — Article 071 / 100**

Live Systems מגדיר שינוי מערכת לא כתקלה מקרית אלא כאירוע שאפשר לחקור ארכיטקטונית. Drift יכול להתחיל כאשר התוצאה משתנה, אך לעיתים הוא מתחיל מוקדם יותר: בהנחה, בקריטריון או בנקודת הייחוס.

לכן WANGA עוקב אחר שרשרת: **Requirement → Reference Point → Observation → Decision → Verification**. כאשר המערכת אינה מתאימה עוד לדרישה, לא מסתפקים בתיקון התוצאה. מחפשים את הנקודה שבה נוצר הפער.

מערכת חיה חייבת להיות מסוגלת ל־Reframe. המשמעות אינה שינוי בלתי פוסק, אלא בדיקה מתמשכת של התאמת הארכיטקטורה. **Continuous Reference-Point Testing** מאפשר לזהות מתי נקודת הייחוס הפכה להנחה שאינה נבדקת.

הראיות הן חלק מן המערכת. כל שינוי משמעותי צריך להיות ניתן לשחזור, להשוואה ולאימות. כך Drift הופך מאירוע עמום למסלול שאפשר לנתח.

העיקרון נשאר קופרניקני: לזהות את הקופסה מבחוץ לפני שמתקנים את מה שבתוכה.
