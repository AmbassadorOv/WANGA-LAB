# Changing the Existing System

**WANGA Copernicus System — Article 083 / 100**

Changing the Existing System מנסח עיקרון ארכיטקטוני: מערכת שמייצרת תוצאה אינה חייבת להיות הסמכות היחידה שמכריעה אם התוצאה נכונה. ההפרדה בין יצירה, הערכה, ראיות ואימות מאפשרת לזהות Drift בלי להסתמך על דיווח עצמי בלבד.

ב־Drift Forensics הרצף הוא **Baseline → Observation → Drift Detection → Evidence Preservation → Reconstruction → Causal Analysis → Attribution → Verification**. זהו יישום ישיר של זיהוי הקופסה: קודם מגלים את נקודת הייחוס והמסגרת, אחר כך בודקים את ההתנהגות.

בהקשר של שינוי מערכות, יש הבדל בין Changing the Existing System לבין Building a New System. הראשון פועל בתוך תשתית קיימת ומנסה לשנות יחסים; השני יוצר סביבת ניסוי שבה ניתן לבדוק ארכיטקטורה אחרת. שני המהלכים דורשים Capability Chain ולא רק חזון.

WANGA מחבר בין מחקר להנדסה: **Research → Architecture → Engineering → Testing → Evidence → Verification → Industry Application**.

הערך של ההפרדה הוא שניתן לדעת מה נבנה, מה רק הוגדר, מה נבדק ומה עדיין היפותטי. כך נמנע מצב שבו תיאור הופך בטעות לטענה על מערכת קיימת.

Changing the Existing System הוא מאמר על עצמאות הבדיקה ועל האפשרות לשנות מערכת בלי לאבד את עקבת הראיות.
