# AI בתוך הקופסה

**WANGA Copernicus System — Article 073 / 100**

AI בתוך הקופסה מחיל את הפעולה הקופרניקנית על מערכות AI. השאלה אינה רק האם המודל נותן תשובה טובה, אלא האם הוא מסוגל לזהות את המסגרת, ההנחות והקריטריונים שמעצבים את התשובה.

ב־**Model → Answer → Evaluation → Correction** כל שלב יכול להשפיע על הבא. אם אותו מודל או אותה מסגרת מגדירים גם את הקריטריון, תיקון יכול להישאר בתוך אותה קופסה.

**Recursive Convergence** מתאר כאן מצב שבו שיפור חוזר ממשיך להתכנס לאותה מסגרת. זה שונה מהשאלה האם מודל יכול להשתפר. השאלה הארכיטקטונית היא האם הוא יכול לבדוק גם את נקודת הייחוס שממנה הוא משפר.

WANGA מציע להפריד בין reasoning, perspective, evidence ו-verification. המודל יכול להציע; שכבות אחרות בודקות, משוות ומשחזרות.

כך AI הופך ממערכת שמנסה להיות צודקת בכל מחיר למערכת שמסוגלת לזהות אי־התאמה ולבקש Reconstruction.

המחזור הוא **Observe → Represent → Reason → Act → Verify → Update Memory → Observe**.
