# Reference Point Detection

**WANGA Copernicus System — Article 062 / 100**

Reference Point Detection הוא רכיב מתודולוגי בארכיטקטורת WANGA. העיקרון הוא שהארכיטקטורה אינה נקודת ההתחלה; היא תוצאה של דרישה שהוגדרה ונבדקה.

**Requirement Before Architecture** מונע מצב שבו מערכת קיימת מכתיבה את הבעיה. **Reference Point Detection** מזהה מאיפה המערכת מסתכלת. **Box Detection** ממפה את הגבול שמגדיר את מרחב הפעולה. **Perspective Layer** מאפשר להשוות נקודות ייחוס בלי לערבב ביניהן.

השלבים מתחברים: דרישה → נקודת ייחוס → קופסה → פרספקטיבות → יחסים → ארכיטקטורה. רק לאחר מכן מגיעים יישום ותצפית.

המשמעות היא שהחשיבה הקופרניקנית אינה "עוד רעיון" מעל המערכת. היא מנגנון שמאפשר לבדוק את התנאים שמהם המערכת נגזרת.

במערכת חיה, כל רכיב נשאר ניתן לאימות. כאשר הראיות משתנות, חוזרים לשלב שבו נוצרה אי־ההתאמה ולא רק מתקנים את התוצאה הסופית.

כך WANGA מייצר מעבר מתכנון ליניארי לתהליך שבו הדרישה, נקודת הייחוס והארכיטקטורה נמצאות בלולאה אחת.
