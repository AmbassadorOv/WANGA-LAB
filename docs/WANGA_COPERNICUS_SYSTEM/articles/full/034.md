# פתרון בלי לשחזר את המסגרת

**WANGA Copernicus System — Article 034 / 100**

פתרון בלי לשחזר את המסגרת עוסק בהפרדה בין פתרון לבין המסגרת שבה הפתרון נוצר. ידע היסטורי יכול להישאר שימושי גם כאשר ההנחות שהקיפו אותו כבר אינן מתאימות.

המתודה הקופרניקנית מזהה תחילה את הדרישה ואת נקודת הייחוס. לאחר מכן היא ממפה את הגבולות, את היחסים ואת הפונקציות. רק אז ניתן לחלץ רכיב בלי לשחזר את כל הקופסה.

העיקרון הוא **Architecture of Relations**: ערך של רכיב תלוי גם במיקומו וביחסיו. לכן "החלק החסר" אינו בהכרח חומר חדש; לפעמים הוא יחס חסר, תרגום חסר או מיקום שגוי.

בנייה מחדש נעשית באמצעות **Backward Reconstruction**: מתחילים מהתוצאה הרצויה, חוזרים אל התנאים הדרושים, ואז מחברים את הרכיבים הקיימים בדרך שמתאימה לדרישה. כל שלב מתועד וניתן לאימות.

המחזור של WANGA — **Observe → Represent → Reason → Act → Verify → Update Memory → Observe** — מונע מהפתרון להפוך למסגרת חדשה שאינה נבדקת.

פתרון בלי לשחזר את המסגרת מדגים מעבר מ"היכן נולד הפתרון" ל"איפה הוא שייך עכשיו". זהו ההבדל בין נאמנות למסגרת לבין נאמנות לדרישה.
