# מדע אינו מלחמה במציאות

**WANGA Copernicus System — Article 008 / 100**

## יסודות

מדע אינו מלחמה במציאות. תפקיד המודל הוא לשרת תצפית, להסביר אותה ולשנות את עצמו כאשר הראיות דורשות זאת. המהלך הקופרניקני מתחיל כאשר מפסיקים להתייחס למסגרת כאל רקע בלתי נראה ומתחילים למדוד אותה כחלק מן המערכת. מכאן אפשר להבחין בין מה שנדרש לבין מה שהפך להרגל.

## הארכיטקטורה

הסדר המבני הוא **דרישה → נקודת ייחוס → גבול → יחסים → ארכיטקטורה → יישום → תצפית → ראיות → אימות → שינוי**. הלוגיקה הרציונלית מספקת עקביות בין הטענות; התוצאה הארכיטקטונית היא היכולת לבדוק גם את התנאים שבהם הטענות פועלות.

כאשר דרישה משתנה, אין להניח שהמערכת רשאית רק לבצע אופטימיזציה פנימית. צריך לבדוק האם המבנה עצמו עדיין מתאים. זהו ההבדל בין תיקון מקומי לבין Reconstruction.

## שיטת העבודה

1. לנסח את הדרישה במונחים ניתנים לתצפית.
2. לזהות את נקודת הייחוס שממנה הבעיה נראית.
3. למפות את הגבולות ואת ההנחות שהם מכילים.
4. להוציא את הגבולות אל שדה התצפית.
5. להפריד רכיבים שימושיים מאילוצים שאינם נדרשים עוד.
6. להרכיב יחסים חדשים מתוך הדרישה.
7. ליישם ולמדוד.
8. לשמור ראיות ולאמת את התוצאה.

היציאה מן הקופסה אינה מחייבת זריקת הידע שבתוכה. היא מחייבת שינוי ביחס בין הידע לבין המסגרת.

## מערכת חיה

WANGA מוסיף למחזור הזה תצפית מתמשכת: **Observe → Represent → Reason → Act → Verify → Update Memory → Observe**. לכן הארכיטקטורה אינה אמורה להפוך לקופסה קבועה חדשה. היא חייבת להישאר ניתנת לבדיקה.

## סיכום

מדע אינו מלחמה במציאות מצביע על אותה פעולה בסיסית: להפוך את נקודת הייחוס מחלק נסתר של הבעיה לרכיב גלוי שניתן לבדוק. כאשר זה נעשה, פתרון אינו עוד ניסיון לנצח את המציאות באמצעות המודל; הוא ניסיון לבנות מבנה שמתאים לדרישה ולראיות.
