# Knowledge Without a Permanent Box

**WANGA Copernicus System — Article 095 / 100**

Knowledge Without a Permanent Box מתאר את השלב שבו מודל הופך לגבול, והגבול דורש בדיקה מחדש. מודל שימושי מאפשר חיזוי והסבר; הוא הופך לבעיה כאשר הוא מתחיל להכתיב מה המציאות חייבת להיות.

WANGA מציע: **Model → Boundary → Reconstruction**. מזהים איזה גבול נוצר מן המודל, בודקים את הראיות, ואז מחליטים אם לשמר אותו, לשנות אותו או להסירו.

Knowledge Without a Permanent Box אינו אומר שאין מבנים. הוא אומר שאין צורך להפוך מבנה זמני לאמת בלתי ניתנת לשינוי. ידע נשמר באמצעות ראיות, יחסים ותיעוד, לא באמצעות הקפאת המסגרת.

לכן אפשר לשמר פתרון בלי לשמר את הקופסה שבה הוא נוצר. מפרידים פונקציה מהקשר, מתעדים את התנאים שבהם הפתרון עבד, וממקמים אותו מחדש כאשר הדרישה משתנה.

זהו שימוש ישיר בעקרון הקופרניקני: **Identify the Box → Exit the Box → Redefine the Problem → Solve**.

המערכת נשארת חיה באמצעות אימות מתמשך ותיעוד של שינויים.
