# מוסדות שנשארו בתוך המסגרת שיצרה אותם

**WANGA Copernicus System — Article 049 / 100**

מוסדות שנשארו בתוך המסגרת שיצרה אותם נבחן דרך השאלה מה קורה כאשר פתרון או מוסד ממשיך לפעול לאחר שהדרישה המקורית השתנתה. המטרה אינה לשפוט את ההיסטוריה אלא לזהות מנגנון.

הניתוח מתחיל בהפרדה בין **פתרון**, **מסגרת** ו־**דרישה**. פתרון הוא פעולה שעונה על צורך; מסגרת היא מערכת התנאים שבהם הוא נוצר; דרישה היא מה שהמערכת צריכה להשיג עכשיו.

כאשר הפתרון נעשה חלק מן המסגרת, הוא יכול להפוך לתנאי שמגביל את האפשרויות הבאות. כאן מופיעה פעולת WANGA: לזהות את הגבול מבחוץ, להוציא אותו לתצפית ולבדוק אם הוא עדיין נדרש.

הקשר לפילוסופיית המדע חשוב אך אינו זהה לה. Kuhn, Popper, Lakatos, Feyerabend, Chomsky, Wittgenstein ו-Foucault מספקים נקודות מחקר שונות על פרדיגמות, ביקורת, תוכניות מחקר, מתודות, מבנים ושפה. WANGA משתמש בדיון הזה כחומר להשוואה, לא כתחליף למקורות המקוריים.

העיקרון הקופרניקני נשאר פשוט: **IDENTIFY THE BOX → EXIT THE BOX → REDEFINE THE PROBLEM → SOLVE**.

כך ניתן לקרוא גם מוסד וגם תיאוריה כארכיטקטורה שניתן למפות: דרישה, נקודת ייחוס, גבולות, יחסים, תוצאה ויכולת התאמה.

המאמר משאיר את המסקנה ניתנת לבדיקה באמצעות מקורות, דוגמאות נגדיות ותצפית.
