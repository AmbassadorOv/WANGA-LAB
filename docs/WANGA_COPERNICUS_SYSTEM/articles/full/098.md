# The Architecture of Scientific Change

**WANGA Copernicus System — Article 098 / 100**

## מאמר מסכם

The Architecture of Scientific Change מסכם את הפעולה שהוגדרה לאורך הקורפוס: שינוי נקודת הייחוס לפני שינוי הפתרון. Reframing אינו קישוט לשוני אלא שינוי במבנה שממנו הבעיה נראית.

המתודה המלאה היא **Requirement → Reference Point → Box Detection → Perspective → Relations → Architecture → Implementation → Observation → Evidence → Verification → Reframing**.

היא מתחילה בדרישה, משום שהארכיטקטורה אינה מטרה בפני עצמה. היא עוברת דרך נקודת הייחוס, משום שאותה צריך להיות אפשר לזהות. היא עוברת דרך יחסים, משום שרכיבים מקבלים משמעות גם לפי מיקומם. והיא חוזרת לתצפית, משום שהמודל חייב להיבדק מול המציאות.

ב־From Puzzle Solving to System Reassembly, הפאזל אינו אוסף חלקים בלבד. הוא מערכת שבה חלקים יכולים להיות נכונים אך ממוקמים ביחסים שאינם מתאימים. לכן Reconstruction מחלץ את החלקים, מתעד את הפונקציה שלהם ומרכיב אותם מחדש.

העיקרון הכללי הוא: **IDENTIFY THE BOX → EXIT THE BOX → REDEFINE THE PROBLEM → SOLVE**. היציאה אינה יצירת קופסה אחרת, אלא שמירה על האפשרות לשנות את הארכיטקטורה כאשר הדרישה משתנה.

WANGA Copernicus הוא בכך שכבת חשיבה חיה: הוא מחבר פילוסופיה, היסטוריה, לוגיקה, מערכות, AI, ראיות והנדסה סביב פעולה אחת — לבדוק את נקודת הייחוס שממנה המערכת פועלת.

זה אינו תיאור של מערכת שהושלמה בכל מרכיביה; זהו קורפוס מחקרי מלא שנועד להפוך את העיקרון למערכת שניתן להמשיך לבדוק, להרחיב ולאמת.
