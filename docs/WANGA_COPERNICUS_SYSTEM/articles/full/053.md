# Lakatos: תוכניות מחקר

**WANGA Copernicus System — Article 053 / 100**

Lakatos: תוכניות מחקר משמש כאן כנקודת מחקר בתוך הארכיטקטורה של WANGA. אין מדובר בסיכום מלא של ההוגה, אלא בבדיקת שאלה אחת: כיצד ידע, מתודה או שפה מגדירים את המרחב שבו אפשר לחשוב.

הפעולה הקופרניקנית היא להפוך את התנאי הזה לנצפה. אם תוכנית מחקר, מתודה, מבנה שפה או מערכת מושגים מגדירים מה נחשב שאלה טובה, צריך להיות אפשרי לשאול גם מי הגדיר את המרחב הזה.

WANGA מפריד בין **תוכן** לבין **מסגרת**. התוכן יכול להיות נכון ושימושי; המסגרת יכולה עדיין להיות מוגבלת. לכן אין צורך לדחות את התוכן כדי לבדוק את המסגרת.

השלב הבא הוא Reconstruction: לקחת את הרכיבים השימושיים, לזהות את היחסים שבהם הם פעלו, ולהרכיב אותם לפי דרישה אחרת כאשר הדבר נדרש.

הקשר ל־Rational Logic הוא עקביות. הקשר ל־Copernican Reconstruction הוא בחינת נקודת הייחוס. הקשר ל־Evidence הוא האפשרות להבחין בין פרשנות לבין מה שניתן להראות.

כך הפילוסופיה הופכת למפת בדיקה עבור ארכיטקטורות חשיבה, בלי להפוך אף הוגה לקופסה חדשה.
