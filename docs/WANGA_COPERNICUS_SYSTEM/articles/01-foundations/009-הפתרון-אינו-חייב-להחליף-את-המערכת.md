## Research thesis

This article is part of the WANGA Copernicus System. Its starting point is the project's core operation: **identify the reference frame from outside the frame before attempting to solve a problem defined inside it.**

The method does not automatically create a new box to replace an old one. It separates useful solutions from inherited constraints and reconstructs the problem from a changed reference point.

## Method

1. Identify the current reference point.
2. Identify the boundary that defines the problem space.
3. Separate observations from assumptions and inherited structure.
4. Move the frame itself into the field of observation.
5. Reconstruct the problem without automatically reproducing the original box.
6. Preserve useful knowledge and remove constraints that are no longer required.
7. Verify the reconstruction against evidence and reality.
