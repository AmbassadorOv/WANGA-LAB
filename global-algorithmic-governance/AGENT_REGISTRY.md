# GAG Agent Registry

This registry turns the documented workstreams in `WORK_MANAGER.md` into traceable repository work packages. An entry here is a project-control role, not evidence of autonomous legal authority or institutional appointment.

| Agent ID | Workstream | Primary output | State |
|---|---|---|---|
| AG-EVIDENCE | Evidence Agent | Claim/evidence matrix, provenance records | ACTIVE |
| AG-INSTITUTIONAL | Institutional Agent | Registration/status package | ACTIVE |
| AG-FINANCE | Financial Systems Agent | Monetary/digital-currency asset inventory | ACTIVE |
| AG-DRIFT | Drift Agent | Drift-forensics integration map | ACTIVE |
| AG-NETWORK | Network Agent | Network/dependency map | ACTIVE |
| AG-STANDARDS | Standards Agent | Interoperability/verification matrix | ACTIVE |
| AG-PUBLICATION | Publication Agent | Public publication package | BLOCKED_PENDING_STATUS |
| AG-ARCHIVE | Archive Agent | Preservation/version/audit records | ACTIVE |

## Execution rule

Each agent works through: `COLLECT -> CLASSIFY -> VERIFY -> ASSIGN -> EXECUTE -> REVIEW -> ARCHIVE`.

No agent may publish an unsupported claim about legal status, regulatory authority, ownership, succession, recognition, appointment, or institutional adoption.

## Current execution boundary

The repository contains substantial pre-existing research assets. Agents must index and connect those assets before moving or replacing them. Preservation and traceability take priority over structural cleanup.
