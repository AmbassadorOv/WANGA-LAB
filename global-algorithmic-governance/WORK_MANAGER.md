## Agent model

Agents are workstreams, not claims of autonomous legal authority. Each agent produces artifacts, evidence, tests, or administrative outputs and reports to the Work Manager.

### Initial agents

- Evidence Agent — source capture, provenance, claim verification.
- Institutional Agent — registration/document control.
- Financial Systems Agent — monetary and digital-currency monitoring research.
- Drift Agent — AI Drift Forensics coordination.
- Network Agent — participating labs, departments, and nodes.
- Standards Agent — protocol and interoperability mapping.
- Publication Agent — prepares public material from verified records only.
- Archive Agent — immutable/versioned research records and audit trail.

## Control rule

No agent may publish an institutional, legal, regulatory, ownership, succession, or recognition claim without a corresponding evidence record or an explicit `PROPOSED`, `CLAIMED`, or `UNDER_VERIFICATION` status.

## Lifecycle

Collect → Classify → Verify → Assign → Execute → Review → Archive → Publish when authorized.
