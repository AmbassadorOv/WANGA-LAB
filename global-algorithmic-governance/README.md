# Global Algorithmic Governance

## Institutional Workspace

This directory is the institutional workspace for the Global Algorithmic Governance project. It is maintained separately from WANGA-LAB and separately from AI Drift Forensics. WANGA-LAB may provide research and computational infrastructure, but it is not the governance institute itself.

## Current status

The institutional/legal status of this project is **pre-registration / organizational preparation**. No statement in this repository should be read as evidence of governmental recognition, regulatory authority, charitable status, public funding, or a completed transfer of rights from another jurisdiction.

## Organizational order

**Umbrella Organization → Global Algorithmic Governance Institute → Online Governance Platform → Departments → AI Agent Network → Technical Programs.**

This hierarchy is defined in `UMBRELLA_ORGANIZATION.md` and `FOUNDATION_ARCHITECTURE.md`. `CONTROL_PLANE.md` defines the execution priority.

## Operating principle

Participation is voluntary. Participation in the framework carries defined technical, evidentiary, transparency, and accountability requirements. The framework is non-exclusive and is not intended to create a monopoly over AI governance, standards, testing, or research.
