# Notary Submission Package

Checklist for submitting an audit evidence package for factual/notarial review.

- Canonical audit JSON
- SHA-256 S1/S2/S3 hashes
- MASTER_CHAIN_HASH
- RFC 3161 timestamp token
- Bitcoin/OpenTimestamps proof, when available
- Contract/legal-agreement hash
- Version identifiers and source manifest
- Identity documents and other materials requested by the notary
- Written description of what the notary is being asked to certify

Notarization does not independently certify the truth of financial claims unless the applicable legal procedure expressly provides for that conclusion.
