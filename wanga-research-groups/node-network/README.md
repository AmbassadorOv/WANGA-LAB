# RG-NODE-NETWORK

Research domain for WANGA Nodes: phones, computers, servers and future dedicated devices.

Agent roles:
- Node Architect
- Protocol Researcher
- Synchronization Worker
- Offline/Online Systems Worker
- Network Verification Worker

Primary outputs: node specifications, handshake protocols, synchronization models, queue semantics and connectivity tests.

Boundary: automatic startup means node initialization and governed registration, not unrestricted access to external systems.
