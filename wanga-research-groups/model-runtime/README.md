# RG-MODEL-RUNTIME

Research domain for connecting local and remote language-model runtimes to WANGA.

Agent roles:
- Model Surveyor
- Runtime Adapter Engineer
- Quantization/Memory Researcher
- Inference Benchmark Worker
- Runtime Verification Worker

Primary outputs: model capability records, runtime adapters, memory requirements, benchmark runs, and compatibility matrices.

Boundary: credentials remain outside source control; model downloads and external inference are separately governed.
