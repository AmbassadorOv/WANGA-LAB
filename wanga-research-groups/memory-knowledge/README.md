# RG-MEMORY-KNOWLEDGE

Research domain for the WANGA memory fabric and scientific knowledge layer.

Agent roles:
- Memory Modeler
- Provenance Worker
- Evidence Analyst
- Knowledge Graph Researcher
- Replication/Verification Worker

Primary outputs: memory schemas, provenance records, evidence indexes, knowledge graphs and replication reports.

Boundary: observations, hypotheses, interpretations and validated findings remain explicitly distinguished.
