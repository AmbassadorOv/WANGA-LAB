# RG-ARCHITECT-INTERFACE

Research domain for the architect-facing environment of WANGA.

Agent roles:
- Interface Architect
- Project Graph Worker
- Visualization Researcher
- Human-in-the-Loop Analyst
- Usability Verification Worker

Primary outputs: architect workspace specifications, project navigation models, visualizations, interaction protocols and usability tests.

Boundary: the interface exposes system state and research results; it does not silently promote unverified agent output to fact.
